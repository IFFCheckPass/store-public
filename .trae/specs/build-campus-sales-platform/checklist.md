# Checklist

- [x] 用户端可免登录浏览商品，商品支持规格选择与颜色切换，切换颜色时浏览图同步变化
- [x] 购物车支持添加、改数量、删除，同商品不同规格/颜色为独立条目，合计金额正确
- [x] 结算页包含收货班级、配送方式、建议时间段（白天课间/午间/傍晚/晚自习间）、联系方式（QQ/微信/电话）且必填校验生效
- [x] 支付方式支持微信与支付宝，弹窗展示操作示例与收款二维码
- [x] 支持上传支付成功截图，本地 OCR 自动带出候选支付单号且允许人工校正
- [x] 截图提交后订单进入待核验，管理端核验通过后转为已付款；驳回可回退并显示原因
- [x] 有效赠货码可让订单跳过支付直接完成，且使用次数正确核销；无效/过期/用尽时被拒绝
- [x] 用户端通过姓名+班级+座号登录后只能查询到本人订单，学号字段已预留
- [x] 生产端与管理端必须输入用户名+学号+密码三要素登录，角色越权被拒绝
- [x] 外部生产端可按单项商品接单并上报待接单/已接单/生产中/已完成/异常状态
- [x] 内部生产端可查看订单逐项商品明细、收货班级、时间段与联系方式，并上报打包/配送状态
- [x] 生产与配送状态变化会同步到订单状态与用户端时间线
- [x] 管理端可查看与管理账号（新建、编辑、重置密码、启停、角色分配），写操作仅最高权限可用
- [x] 管理端可查看全部订单详情，包含支付截图、支付单号、赠货码、生产与配送进度
- [x] 仅最高权限账号可生成赠货码，可设置次数与有效期并启停
- [x] 删除订单需至少 2 个不同最高权限账号确认后才生效，未达标时订单保持可见
- [x] 关键操作写入审计日志并在管理端可查询
- [x] 首启自动写入演示种子数据，`npm install && npm start` 可正常运行
- [x] 冒烟测试脚本覆盖登录、下单、赠货码、支付核验、生产流转、删除审批并通过
- [x] 三端界面在常见桌面分辨率下布局正常，视觉风格统一为校园清新明亮
